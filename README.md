# Mini-Project-On-Student-Management-System
Training Program: New Leaf Training
Language: C Programming
Project Description:
Student Management System is a console-based mini project developed in C as part of New Leaf Training.
The project is designed to help teachers store and manage student academic records efficiently.
It allows the user to enter important student information such as roll number and name.
The system accepts marks for three subjects: C, Java, and DB.
It automatically calculates the total marks and average marks.
Based on the average, the system assigns a grade from A to F.
Users can display all registered students along with their results.
The system also provides a search option to find a student using their roll number.
A simple menu-driven interface makes the program easy to use.
The project demonstrates practical implementation of structures, arrays, functions, loops, conditional statements, pointers, and input/output operations in C.
This project helped in developing practical programming skills and understanding how basic C concepts can be combined to create a functional application.
